Week 8: Introduction to Oceanographic Data Analysis Using R (oce)

UCSB R Seminar — Fall 2026

This workshop introduces oceanographic data analysis using the R package oce.

Topics include:

Introduction to oceanographic data and instruments

CTD profiles and oceanographic sections

Understanding S4 classes in R

Interpolation of oceanographic measurements

Argo floats and oceanographic data visualization

Workshop Materials

PowerPoint presentation: Oceanography_oce.pptx

R code: oce_lesson.R

Getting Started

Install and load the oce package in RStudio:

install.packages("oce")
library(oce)
